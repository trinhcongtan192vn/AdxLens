## Hệ quả
- Giá gói, ngưỡng rule audit vẫn là giá trị cấu hình tạm; PM chỉnh trong một file cấu hình mà không cần sửa code.
- Mọi thay đổi chạm vùng bảo vệ (`execution`, `db`, `infra`, `flags`, `connections`) gom vào PR `develop → main` để PM duyệt; mô tả PR liệt kê rủi ro từng vùng.
